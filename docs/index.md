# Akeratos documentation

I train small language models from scratch on one Mac with MLX, to test one idea: a large learned n-gram table beside the model. These pages say what I trained, how to rerun it and how the code works.

- [Billet and its twin](billet.md): the result and every readout.
- [The analysis plan for Billet and its twin](analysis-plan.md): the comparison's rule, word for word.
- [Reproduce Billet and its twin](reproduce.md): build the data, train both models and score them.
- [The Mac speedrun](speedrun.md): the 5-minute track, sending a claim, and `bake bench`.
- [The n-gram memory](learn/n-gram-memory.md): how the table finds, learns and stores its rows.
- [Training on a Mac](learn/apple-silicon.md): unified memory, MLX, and long runs on a laptop.
- [Code map](architecture.md): the files, and one training step through them.
- [MLX notes](mlx-notes.md): the MLX versions and the MLX problems worked around.
- [Training a language model on a Mac: the options](mac-options.md): what Akeratos and other Mac projects are each for.

[`OPEN_PROBLEMS.md`](https://github.com/cogvera-labs/akeratos/blob/main/OPEN_PROBLEMS.md) lists the questions I want answered. [`CONTRIBUTING.md`](https://github.com/cogvera-labs/akeratos/blob/main/CONTRIBUTING.md) says how to send a change.
